# Mockups (first round)

**Superseded by [`../design/`](../design/)** (the full design handoff, 2026-11-06): kept for history.

The first app mockups (2026-11-06), 390×844 screens:

- `maquettes.html`: the original bundle, open it in a browser to see all eight screens;
- `ios-*.html`, `android-*.html`: the markup of each screen, extracted from the bundle for reference (fonts removed).

| Screen | iOS | Android |
|---|---|---|
| Conversations | `ios-conversations.html` | `android-conversations.html` |
| Chat | `ios-discussion.html` | `android-discussion.html` |
| Map and location | `ios-carte.html` | `android-carte.html` |
| Search mode | `ios-recherche.html` | `android-recherche.html` |

The on-screen text is in French. The apps ship English text with a French translation.
